---
title: Erste Anwendungsversion verfügbar - VoteEasy ist damit frei
date: 2026-11-01
---

Auf GitHub ist ab jetzt die erste Version der VoteEasy-Webanwendung verfügbar, die unter der Lizenz [AGPL v3.0](https://www.gnu.org/licenses/agpl-3.0.de.html) steht.
Damit kann die Anwendung lokal installiert und ausprobiert werden.

Das nötige Repository ist [https://github.com/voteeasy/webapp](https://github.com/voteeasy/webapp).

Die Anwendung selbst ist eine Spring-Boot-Anwendung, die mit [Maven](https://maven.apache.org/) gebaut werden kann.
Mittels Docker kann auch PostgreSQL als Datenbank verwendet werden.

Weitere Informationen findest Du in der [README-Datei](https://github.com/voteeasy/webapp/blob/main/README.md).
